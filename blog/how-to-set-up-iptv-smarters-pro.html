How to Set Up IPTV on IPTV Smarters Pro (Step-by-Step)

IPTV Smarters Pro runs on nearly every device, which makes it a common first app for new IPTV subscribers. Setup takes a few minutes: install, choose your login type, enter your details, and go.

Step-by-step instructions

  1. Install IPTV Smarters Pro. Download it from the App Store (iOS), Google Play (Android), Amazon Appstore (Firestick), or the official site for Windows/Smart TV versions.
  2. Pick your login method. On the welcome screen, choose Login with Xtream Codes API or Load your playlist or file URL (M3U), matching what your provider gave you.
  3. Enter your details. For Xtream Codes: server URL, username, and password. For M3U: the playlist URL. Name the profile anything you like.
  4. Add the playlist. Tap Add User / Add Playlist and let it load your channels and program guide.
  5. Watch. Open Live TV from the home screen to browse channels.

Frequently asked questions

Is IPTV Smarters Pro available on iPhone?

Yes. IPTV Smarters Pro is one of the few major IPTV player apps available on iOS as well as Android, Fire TV, and Windows.

What's the difference between "Xtream Codes" and "M3U URL" login on Smarters?

Xtream Codes login uses a server address, username, and password. M3U URL login uses a single playlist link. Use whichever format your provider gave you.

Can I add more than one subscription to IPTV Smarters Pro?

Yes, the app supports multiple user profiles, so you can add more than one playlist and switch between them.
