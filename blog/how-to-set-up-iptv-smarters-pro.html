How to Set Up IPTV on IPTV Smarters Pro (Step-by-Step)

IPTV Smarters Pro runs on nearly every device, which makes it a common first app for new IPTV subscribers. Setup takes a few minutes: install, choose your login type, enter your details, and go.

Step-by-step instructions

  1. Install IPTV Smarters Pro. Download it from the App Store (iOS), Google Play (Android), Amazon Appstore (Firestick), or the official site for Windows/Smart TV versions.
  2. Pick your login method. On the welcome screen, choose Login with Xtream Codes API or Load your playlist or file URL (M3U), matching what your provider gave you.
  3. Enter your details. For Xtream Codes: server URL, username, and password. For M3U: the playlist URL. Name the profile anything you like.
  4. Add the playlist. Tap Add User / Add Playlist and let it load your channels and program guide.
  5. Watch. Open Live TV from the home screen to browse channels.

Setting up parental controls

Smarters Pro includes a built-in PIN lock for restricting categories, useful if kids have access to the same device. Go to Settings → Parental Control, set a PIN, and choose which categories to lock behind it. Once set, opening a restricted category prompts for the PIN every time, it's a per-category setting, not an all-or-nothing switch, so you can lock specific categories while leaving the rest open.

Adding your program guide

If your provider's Xtream Codes login doesn't automatically populate the guide, Smarters Pro has a separate EPG option under the profile's settings, look for an "EPG URL" field when editing your playlist and paste the URL your provider supplied there. Guide data not showing is almost always this setting being blank rather than anything wrong with your channels.

Watching something that already aired (catch-up)

On channels that support it, Smarters Pro lets you rewind into the program guide and play a show that already aired rather than just what's live right now, look for a small rewind or play icon next to a past time slot in the EPG. Not every channel includes catch-up data, it depends on what your provider's channel feed supports, but where it's available it works directly from the same guide screen you'd use to check what's on.

Frequently asked questions

Is IPTV Smarters Pro available on iPhone?

Yes. IPTV Smarters Pro is one of the few major IPTV player apps available on iOS as well as Android, Fire TV, and Windows.

What's the difference between "Xtream Codes" and "M3U URL" login on Smarters?

Xtream Codes login uses a server address, username, and password. M3U URL login uses a single playlist link. Use whichever format your provider gave you.

Can I add more than one subscription to IPTV Smarters Pro?

Yes, the app supports multiple user profiles, so you can add more than one playlist and switch between them.

How do I set up parental controls in IPTV Smarters Pro?

Go to Settings → Parental Control, set a PIN, and choose which categories to lock. It's per-category, so you can restrict specific categories while leaving others open.

Does IPTV Smarters Pro support catch-up TV?

Yes, on channels where the provider's feed includes catch-up data. Rewind into the program guide and look for a play or rewind icon next to a past time slot to watch something that already aired.
