How to Set Up IPTV on PC, Mac, MAG Box & Formuler

These three device types don't use the typical app-store setup. Here's exactly what each one actually needs.

PC and Mac

No special hardware required, either of these works:

  1. IPTV Smarters Pro (recommended). Download the Windows or Mac version from their official site, open it, and choose "Login with Xtream Codes API." Enter the server URL, username, and password from your TruWave TV credentials.
  2. VLC media player. If you prefer something simpler, open VLC → Media → Open Network Stream, and paste your M3U playlist URL directly. This gives you playback without a full program guide interface.

MAG Box

MAG boxes don't use installable apps. They run a built-in "Portal" interface instead. Setup happens directly in the box's system settings, not an app store:

  1. On the box, go to Settings → System Settings → Servers (menu naming varies slightly by model/firmware).
  2. Look for Portal Type. By default this is usually set to "Stalker Portal." Change it to Xtream or M3U, whichever your box's firmware offers.
  3. Enter the Portal URL and your Xtream Codes credentials (or the M3U URL directly, if using the M3U option).
  4. Save and restart the box. Channels and the guide should load automatically.

If your specific MAG firmware only offers a "Stalker Portal" option with no Xtream/M3U mode, message us on WhatsApp. Older firmware sometimes needs a specific portal link format.

Formuler

Most Formuler boxes use the same Portal-based setup as MAG boxes above. The menu structure is very similar, typically under Settings → Playlist/Portal Settings. Set the Portal Type to Xtream or M3U and enter your credentials the same way.

If you have a newer Formuler model running full Android TV, you have another option: install TiviMate directly from the Formuler app store and set it up exactly like an Android TV box.

Not sure which option applies to your exact model? Message TruWave TV on WhatsApp with your device model and we'll walk you through the right setup directly.

Frequently asked questions

Can I watch IPTV on a regular PC or Mac?

Yes. Using a player app like IPTV Smarters Pro (Windows/Mac) or VLC media player with your Xtream Codes login or M3U playlist URL. No special hardware is needed.

Does a MAG box use the same setup as Firestick or Android apps?

No. MAG boxes use their own built-in Portal interface rather than installable apps. You set the Portal Type to Xtream/M3U in the box's settings menu and enter your credentials there.

Does Formuler work the same way as MAG?

Most Formuler models support the same Portal-based setup as MAG boxes. Newer Formuler models that run Android TV can alternatively install a standard app like TiviMate from their app store.
